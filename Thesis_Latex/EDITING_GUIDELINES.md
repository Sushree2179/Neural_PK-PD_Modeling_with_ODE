# Diploma Thesis Editing Guidelines
> Source: `readme_en.txt` — Warsaw University of Technology, Faculty of Mathematics and Information Science

---

## 1. Required Document Structure (in order)

1. **Title page** — do **not** change font types or sizes
   - Bachelor's thesis template
   - Master's thesis template CSaIS
   - Master's thesis template DS
   > **Engineering thesis note:** The "consultation" inscription and name below it refer to the scientific tutor — required only when the supervisor holds an MSc degree (not PhD). If the supervisor holds a PhD or higher, **remove** the "consultation" inscription entirely.

2. **Abstract in English** — includes thesis title and 4–6 keywords; one page, single line spacing, font size 12

3. **Abstract in Polish** — includes thesis title in Polish and 4–6 keywords; one page, single line spacing, font size 12

4. **Abstract in a foreign language** *(optional)* — required only if the student applies for a diploma in a language other than English or Polish; same format as above

5. **Table of contents**

6. **Description of work division** *(team projects only)* — covers each co-author's contribution to both the practical and descriptive parts

7. **Chapters of the thesis**

8. **References**

9. **List of symbols and abbreviations**

10. **List of figures**

11. **List of tables**

12. **List of appendices**

13. **Appendices**

## 2. Editing Rules

| Element | Rule | Status |
|---|---|---|
| **Paper & printing** | Duplex printing, A4 | **Required** |
| **Margins** | Inside: 30 mm · Outside: 20 mm · Top & Bottom: 25 mm | Advisable |
| **Typeface** | Sans-serif, size 11 (e.g. Arial, Verdana) | Advisable |
| **Line spacing** | 1.15 | Advisable |
| **Page numbering** | Bottom of page, outer side; mirror position on odd/even pages | **Required** |
| **Paragraph indent** | 0.5 cm indent · OR no indent with 4 spaces before paragraph | Optional |
| **References style** | Numbering per Polish Norm · OR Harvard style | Optional |
| **Figure/table numbering** | Continued throughout the thesis · OR separate per chapter | Optional |
| **References order** | Alphabetical by author surname | Advisable |
| **Table title** | Above the table · left-justified · sans-serif · size 9 | Advisable |
| **Figure caption** | Below the figure · left-justified · sans-serif · size 9 | Advisable |
| **Source label** | Below the figure or table · left-justified · sans-serif · size 9 | Advisable |
| **Subchapter depth** | Maximum **3 levels** | **Required** |
| **First-level subchapters** | Start on a new page | Advisable |
| **Listing style** | Only a bullet point (•) or a dash (–) | Advisable |
| **Footnotes** | Continued numbering throughout the whole thesis · sans-serif · size 9 | Advisable |

## 3. Chapter Title Formatting

> Bold, sans-serif typeface — sizes by level:

| Level | Type | Font Size |
|---|---|---|
| 1st level (Chapter) | Bold, sans-serif | **14 pt** |
| 2nd level (Section) | Bold, sans-serif | **13 pt** |
| 3rd level (Subsection) | Bold, sans-serif | **12 pt** |

---

## 4. Font Note

> \* In theses with a large number of mathematical formulae and calculations, it is permitted to use **serif typefaces** (e.g. Times New Roman) instead of sans-serif.

---

## 5. Quick Compliance Checklist

- [ ] Title page fonts unchanged
- [ ] English abstract: 1 page, single spacing, size 12, 4–6 keywords
- [ ] Polish abstract: 1 page, single spacing, size 12, 4–6 keywords
- [ ] All required sections present in correct order
- [ ] Margins: inside 30 mm, outside 20 mm, top/bottom 25 mm
- [ ] Page numbers at bottom outer edge, mirrored
- [ ] Paragraph indent 0.5 cm
- [ ] No more than 3 subchapter levels
- [ ] First-level chapters start on a new page
- [ ] Table titles above tables, left-justified, size 9
- [ ] Figure captions below figures, left-justified, size 9
- [ ] References in alphabetical order
- [ ] Footnote numbering continuous throughout the thesis
